Yoobee Car Rental System

Developed as the core project for the Professional Software Engineering (MSE800) course. This Python-based application automates vehicle rental operations, managing everything from inventory to role-based user access.

Tools & Technologies
Python VS Code Miro GitHub SQL Integration
OOP & Architecture
  • Singleton Pattern: Ensures a single data instance for consistency.
  • Layered Design: Separation of Data, Domain, and Application layers.
  • Encapsulation: Secured internal states for Users and Vehicles.
