Yoobee Car Rental System

Python CLI application that automates vehicle rental operations with SQLite persistence and role-based access (Customer, Admin, Master). Built as Assessment 1 for Professional Software Engineering (MSE-800) at Yoobee, applying OOP principles including inheritance, polymorphism, and encapsulation.

Tools & Technologies
Python SQLite OOP CLI PyInstaller GitHub
Highlights
  • User management: Register/login with Customer, Admin, and Master roles.
  • Fleet management: Admins add, update (mileage/rate), and delete vehicles.
  • Booking flow: Customers view cars, calculate fees (including delivery), and request bookings.
  • Approvals: Master approves Admin accounts; Admins confirm/reject reservations; Master can delete accounts.
  • Architecture: User base class with Customer/Admin polymorphism; RentalSystem engine for DB and business logic.

* Source: MSE_800_Assessment_1 (documentation & UML included).

Role & Scope
  • Sole developer — designed and built the CLI rental system end to end.
  • OOP design: User base class, Customer/Admin polymorphism, RentalSystem engine for SQLite and business logic.
  • Packaged as a Windows executable (PyInstaller) with seeded demo accounts for marking.
  • MSE-800 Assessment 1 · Yoobee College of Creative Innovation
